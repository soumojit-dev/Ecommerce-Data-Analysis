## 🚀 Overview

This project is a comprehensive end-to-end data analytics workflow performed as part of my Data Analytics internship at **ApexPlanet Software Pvt. Ltd**.

The objective of this project is to analyze an e-commerce dataset to uncover insights related to **revenue performance, delivery efficiency, and customer satisfaction**, and to present them through dashboards and data storytelling.

The project follows a complete analytics pipeline:

> **Raw Data → Data Cleaning → Analysis → Visualization → Dashboard → Data Story → Statistical Validation**

---

## 🧠 Key Objectives

- Analyze business performance using data-driven techniques  
- Identify factors affecting customer satisfaction  
- Evaluate delivery efficiency and operational performance  
- Build dashboards for business insights  
- Validate findings using statistical methods  

---

## 📂 Dataset Description

The dataset consists of multiple relational tables, including:

- Customers  
- Orders  
- Order Items  
- Payments  
- Reviews  
- Products  
- Sellers  

These tables were integrated into a **single master dataset** for analysis.

## 📊 Key KPIs

- 💰 Total Revenue: 16.64M  
- 📦 Total Orders: 98,666  
- 🛒 Average Order Value: 168.64  
- 🚚 Average Delivery Time: ~12 days  
- ⏳ Late Delivery Rate: ~8%  
- ⭐ Average Rating: ~4.0  

---

## 🔍 Key Insights

- Revenue is concentrated in a few high-performing product categories  
- Credit cards dominate transactions (~74%)  
- Most deliveries occur within 5–15 days  
- Late deliveries significantly impact customer satisfaction  
- Delivery time shows a negative correlation with review score  

---

## 🧪 Statistical Validation

A two-sample t-test was performed to validate the impact of delivery performance on customer ratings.

- **T-statistic:** 92.22  
- **P-value:** < 0.001  

📌 Result:  
There is a statistically significant difference between review scores of on-time and late deliveries, confirming that **delivery delays negatively affect customer satisfaction**.
